# Element checklist: Immigrant Defense Project criminal-immigration worksheet

Publisher: Immigrant Defense Project (IDP).

Terms status: restricted or unstated (Catalog v2.1 Section 6); the current published terms were not read in this stage and are to be confirmed before any use beyond this checklist.

Status: not yet compared with the form. The elements are MHSB's expectation of what the form covers, not a verified inventory.

Use: element checklist only. This file lists what the form covers, in MHSB's words. It contains none of the form's wording and is not a substitute for the form.

Scope: Facts needed for an attorney's review of immigration consequences.

## Elements covered

### Status

- [ ] Country of birth and citizenship.
- [ ] Current immigration status and its expiry, distinguishing document types.
- [ ] A-number where one exists.
- [ ] Date and manner of entry.
- [ ] Prior applications, grants and denials.

### History

- [ ] Travel outside the country with dates.
- [ ] Prior removal or proceedings.
- [ ] Detention history.
- [ ] All prior arrests, charges and dispositions, including minor offenses.

### Family

- [ ] Relatives with status or citizenship, relevant to relief.
- [ ] Dependents.

### Handling

- [ ] Every eligibility question is an attorney flag, never a score.
- [ ] Status, entry manner, criminal history and national origin are excluded from scoring and masked in reports.
