# Element checklist: Washington State Bar Association practice management resources

Publisher: Washington State Bar Association (WSBA), Practice Management Assistance.

Terms status: restricted or unstated (Catalog v2.1 Section 6); the current published terms were not read in this stage and are to be confirmed before any use beyond this checklist.

Status: not yet compared with the form. The elements are MHSB's expectation of what the form covers, not a verified inventory.

Use: element checklist only. This file lists what the form covers, in MHSB's words. It contains none of the form's wording and is not a substitute for the form.

Scope: Client intake and conflict records; engagement, non-engagement and closing; file retention.

## Elements covered

### Intake and conflicts

- [ ] Prospective client identity and contact.
- [ ] Related persons and entities for the conflict check.
- [ ] The conflict result and who cleared it.
- [ ] A record that no confidential detail was taken before the conflict check.

### Engagement and scope

- [ ] Client identity, including the entity where an entity is the client.
- [ ] Scope and limits of the representation.
- [ ] Fee basis, advance fees and trust handling.
- [ ] Communication expectations.

### Closing and retention

- [ ] Statement that the matter is concluded.
- [ ] Outstanding items and who owns them.
- [ ] File retention period and destruction notice.
- [ ] Return of original documents.
