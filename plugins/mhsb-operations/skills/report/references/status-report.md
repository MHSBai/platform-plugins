# Status report cover for the firm's periodic reports

This reference governs the narrative cover that `/report` places above a weekly or monthly run for the firm's owner or managing attorney. The cover summarizes the report tables beneath it. It introduces no figure that is not in a report, and it is read by the responsible person before anyone else sees it.

## Shape

```
Status: {firm operations}, {period}
Prepared: {date, firm time zone} | Reports included: {list}

Summary
{three or four sentences: what is in order, what needs attention, what changed}

Overall: On track | Needs attention | Off track
{one sentence giving the reason}

Key figures
| Figure | Firm target | This period | Previous period | Direction |
| {for example open matters, stale matters, consults held} | {from the Firm Profile, or "none set"} | | | up, down or level |

Completed this period
- {from the record: matters opened, matters closed, engagements signed}

Open items
| Item | Responsible person (role) | State | Date in record |

Risks
| Risk | Effect | Current handling | Responsible person (role) |
{for example matters past the stage-age threshold, records without a limitations date}

Decisions requested
| Decision | Reason | Date needed | Option the data supports |

Next period
1. {priority}
2. {priority}
3. {priority}
```

## Rules

1. The first three lines carry the substance; a reader who stops there has the essential position.
2. Status is stated in words, never by color alone.
3. Each figure cites the report it comes from. A target appears only when the Firm Profile records one; otherwise "none set".
4. Risks are stated plainly. A data gap that affects a figure is a risk and is listed.
5. A "decision requested" offers the option the data supports and states that the decision belongs to the firm.
6. Staff are named by role in any output that leaves the responsible person's hands; the report tables follow the authorization scope.
7. Dates are those entered in the record; the cover computes no deadline.

## Not performed

Posting to chat, emailing, or drawing on chat or calendar content the authorization scope does not include.
