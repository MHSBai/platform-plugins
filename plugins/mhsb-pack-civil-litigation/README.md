# mhsb-pack-civil-litigation

General civil litigation practice fragment. Pilot only; installed by MHSB for a named firm. Data only; adds no commands.

Release tier: pilot. License: `LicenseRef-MHSB-Source-Available`. Version: 0.2.0.

Contains no commands. The fragment in `fragment/fragment.yaml` is merged into the Firm Profile and is overridden by the firm's own answers. Templates in `templates/` carry adoption records; the generator fills variables only.

This plugin is not listed in the marketplace. MHSB installs it for a named firm once the release conditions in the design are met.

## Scope

The plugin does no legal research, drafts no filings, produces no citations, takes no trust account action, sends nothing, deletes nothing and, in version 1, writes nothing to the firm's platform. Outputs require review by a licensed attorney.

## Adapted fragment sources

The fragment is accompanied by `fragment/intake-blocks.yaml`, `fragment/sources/chronology.md`, `fragment/sources/legal-hold.md`, `fragment/sources/matter-briefing.md`. Each file names its source, commit and license in its header and has a row in the repository's `PROVENANCE.md`.
